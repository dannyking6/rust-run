# Cargo Rush

## About the game
Buckle up and put the pedal through the floor: this is a full-throttle dash to the evacuation point, and the road absolutely does not want you to get there. Weave through barricaded traffic, blast off ramps, dodge rolling obstacles and hold onto a rocket-fed nitro that turns every straight into a gamble. The ride starts gentle, then the world gets angrier — tighter gaps, faster rivals, nastier surprises — until every meter feels earned.
What makes it sing is the feedback: the engine snarls, the nitro crackles, near-misses pay gold, and the run ends in one of two glorious ways. Controls are one-thumb simple on mobile (hold right/left, tap the nitro), arrow keys on desktop, and the whole thing is pick-up-and-play addictive — die, learn one new trick, come back four seconds faster than last time.

## Controls

### Smartphone & tablet
Hold the left side of the screen to steer left, the right side to steer right. Tap the nitro button for a speed boost.
> Portrait orientation recommended; the game will ask you to rotate your device if needed.

### Desktop
Left/right arrow keys (or A/D) to steer, Up arrow (or W) for the nitro, Down arrow (or S) to brake.
> Trackpad: single click = same as left-click.
